## 1. 明确闭环对应与一对一的作用范围

分别定义开→开、开→闭、闭→开、闭→闭时允许的切点、方向和匹配。
场景闭链可用严格递增索引提升且跨度小于链长表达“最多绕一圈”，
同时按原始像素 ID 防止重复。tiny oracle 必须覆盖所有合法切点和方向。

增加两类相反用例：同一模板链复用场景像素应拒绝；不同模板链复用
该像素按当前方案应允许。提案“允许重复像素必须被拒绝”的合成合同
应注明链内范围，避免 oracle 无意实行全局一对一。有限 tiny 穷举只能
验证所列小域；一般精确性仍需递推正确性论证。

## 2. 保存模板链的可重放坐标来源

固定训练图和官方 mask pin、crop、warp 矩阵、角度/尺度位模式、
bank ID、各层 origin，以及完整链、采样点和格归属。明确公式：

~~~text
q_padded  = match + p_canvas - tl
q_original = q_padded - padding
~~~

沿用 V14 的原 bank 模板逐层精确回放检查，并加入不对称、负相对
坐标和图像边界例。warped_mask_bbox 只是框，不能代替有序边缘序列的
来源证明。

## 3. 将 NMS 非单调性列为必须通过的回归例

三候选按 rank 为 a、b、c；a 抑制 b、b 抑制 c、a 不抑制 c。
A 可输出 a/c；B 删除 a 后会输出 b，并压掉 c。因此即使逐候选
score_B≤score_A、pre-NMS 接受集 B⊆A，post-NMS 集合和 GT 召回
仍不单调。冻结这些逐候选不变量与独立 NMS/GT 重算检查。

A/B 的纯 FP 收益须同时满足实际身份保留条件。400 帧未完整结束时，
不能用子集通过率决定阈值或继续策略；提案已有的禁止子集择优应保留。

## 4. 先冻结循环求解与独立审计的最坏预算

除样本数 N，还须规定兼容边 E、涉及场景链数、周期切点数、状态数
及对应复杂度；稀疏输入不能保证枚举循环切点便宜。明确统一格权重和
精确阈值比较，保证优化目标与 A 完全一致。

完整证据必须足以重建兼容图并独立重算最优分数；witness 哈希只能
验证一致性。将这些证据的生成、读取和审计纳入预算，再批准真实运行。
