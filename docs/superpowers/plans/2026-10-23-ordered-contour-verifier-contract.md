## 2. 边缘图、链与采样的确定性定义

新证据沿用 V14 的**RGB 来源图经 `IMREAD_GRAYSCALE` 转换**、warp/crop、7×7 blur、
Sobel 及 unspread unsigned8 标签配方。不要把“RGB 来源”写成“对 RGB 三通道计算新梯度”。
模板 eligible 标签必须同时通过官方 warped mask 和严格强阈值平方幅值>1600；场景标签
使用原弱阈值20的 unspread quantize 结果，不凭本文重新猜测 histogram/阈值实现。
真正执行前须 pin 完整配方源码及 native 类型，模板与场景不能使用不同的标签解释。
无效值固定255；有效值只能0..7，spread 多 bit 不能当作单标签。

对 eligible 图使用确定性的 Zhang–Suen 两子迭代细化：每个子迭代只读该子迭代开始时的
位图，批量删除后再进入下一子迭代；邻域按 N、NE、E、SE、S、SW、W、NW 排列，图外为0。
第一子迭代删除条件为邻居数2..6、循环邻序（含NW→N）的0→1转换数=1、`N*E*S=0`、`E*S*W=0`；第二次末两项
为`N*E*W=0`、`N*S*W=0`。两次均无删除时终止。幸存像素保留原 eligible 标签，不从邻点
复制方向。输入 eligible 网格、幸存网格、迭代删除数均入证据。

细化后以所有8邻接无向边构图。物理像素 ID 固定为 `y*width+x`，排序等于 y/x 顺序。
每条无向边恰被分解一次：

1. 按像素 ID 遍历 degree≠2 的非孤点；按邻居 ID 从尚未使用的边出发，沿 degree2 节点
   走到第一个 degree≠2 的节点，得到最大 trail。不越过该终点去猜另一条分支。
2. 若 trail 回到自己的起始分叉点，将其明确归类为**返回环**：最后重复的起点只存一次，
   闭合边单独保留，属于闭链。环只沿这条已提取 trail，不能在该分叉改走别的邻边。
   这是一项补充原提案的具体选择，root 可在冻结前驳回；不能留给实现临场决定。
3. 剩余边必在全 degree2 的连通分量中，各生成一个闭链。degree0 节点生成单点开链。

开链取正、反完整物理像素序列中字典序较小者；闭链取所有循环移位及反向中的字典序
最小序列。闭链所有物理 ID 唯一，列表尾部不重复起点。按 `(规范像素序列, 开闭类型)`
排序分配稳定 chain ID。共享分叉点可属于多条链，但单链内部没有重复物理像素。
不能把“严格递增序号”用于一个含重复端点 ID 的序列，再误称物理像素不复用。

模板在规范链上采样，轴向边长1000、对角边长1414。开链包含首尾；另外对每个
`2000*k`（严格小于总弧长）取从首点开始累计弧长第一次达到该值的实际节点。闭链总弧长
包含闭合边，使用同一标记；标记落在最后闭合边上时选下一圈的首点。物理 ID 去重后仍按
规范链序存储。场景不隔点采样，保留全部幸存节点。

一个模板物理像素若被多链采到，由最小 chain ID 拥有且计分一次；其余链保留拓扑节点，
不再拥有该评分样本。采样、所有权及4×4格在对应求解前固定，**切点/方向枚举不重新采样、
不改变分母**。短链和单点不删除；无评分样本的链贡献0但保留其数量/拓扑记录。若整个模板
无评分样本，整个实验为输入合同失败，不能静默放行或拒绝该模板的候选。

该分解不证明轮廓属于同一物体。厚边、8邻接对角接触、细化断裂、共享分叉和长直线仍会
影响判别。记录细化前后节点/分量、chain长度、孤点、分叉、闭链及返回环分布，不因分布
不好看而删除片段或改连接法。

## 3. 完整来源和坐标连接

训练证据必须从官方训练图与 mask pin 出发，保存以下重放链：

`source RGB/mask → decode flag → crop → warp matrix/canvas → eligible label grid
→ thinned graph → canonical chains → owned samples/cells → own C0 L0 origin`。

每个模板记录自身的 `(bank SHA, object/class, template ID, training member, angle bits,
scale bits)`。ID 只能在该 bank 中解释。记录源文件大小/SHA、crop四整数、canvas宽高、
插值/边界模式、六个仿射矩阵 double bit patterns、warp图/mask的行序字节 pin、完整链和
所有 sample 的 canvas坐标、label、cell、chain序号及所有权。mask bbox 只是框，不能
代替完整链的来源。矩阵参数的十进制日志不能代替位模式。

warp 使用原 C0 训练的实际几何合同，不在此发明新画布。V14 的参考实现以 mask bbox crop，
`side=align16(ceil(hypot(crop_w,crop_h)*scale)+2*border)`，以 crop 中心旋转缩放并平移到
canvas中心，图像 bilinear、mask nearest、常量0边界。执行时须与所选 C0 的真实配方逐项
一致；若不同，引用其 own 配方并在冻结前解决，不能拿 V14 的几何替代掉 C0 的。

额外 grayscale 边缘证据不授权改变 C0 bank 的通道语义。原 C0 模板精确回放必须使用
**原训练实际 decode/warp/core 参数**，逐层比较 level、width/height、`tl_x/tl_y`、有序
feature `(x,y,label)` 及所有已序列化 matching 字段；新证据可以来自同一源图的另一条
已声明转换链。两者不能因 source 文件相同而被称为数值相同。训练失败姿态也保留。

对每个评分点保持 int64 canvas坐标 `p_canvas`，一次性得到
`p_rel = p_canvas - own_C0_L0_tl`。候选的 match 坐标本来就在其冻结 padded query 中：

~~~text
q_padded  = (match_x,match_y) + p_canvas - (tl_x,tl_y)
q_original = q_padded - (padding_left,padding_top)
~~~

不再次旋转/缩放已经 warp 的点，不再加一次 crop origin，也不再次补边。场景的原图尺寸、
left/top/right/bottom、padded尺寸、填充值及行序网格 pin逐帧绑定所选 C0 stage；不是假定
所有历史 stage 都有相同 padding。若采用 V31 的848×848共同画布，须绑定该 stage 本身。
原 C0 检测框保持原字节，不从新边缘 bbox 重造。

数值回归例：`p_canvas=(6,2), tl=(10,7), match=(64,70)`，则相对坐标`(-4,-5)`、
`q_padded=(60,65)`；left/top为64时，`q_original=(-4,1)`。它在 padded 内而在原图外，
这两种比例应分开记录。若 `q_padded.x=-1`，即使半径内有 x=0 的兼容像素，该评分点仍
unsupported，保留原分母；不能用邻域裁剪把越界中心救回。所有加减先做有界整型校验，
溢出是合同错误，不是普通 unsupported。

必须包含非对称 crop/mask、非零 origin、负相对坐标、奇数图宽、非连续 ROI、图像边界及
非对称 padding 的合成坐标回归。几何精确回放证明与 bank 的连接；它不独立证明新梯度
标签从源像素生成正确，后者的审计范围见第7节。

## 4. 兼容图、精确权重和四种开闭情况

固定候选与模板链 T。每个 owned 模板样本为一个物理点 i；每条场景链 S 中的每个物理节点
为一个点 j。仅当下列条件同时成立时存在边 `(i,j)`：

- 预测中心 `q_padded(i)` 在 padded网格内；
- j 是该场景细化图的有效节点，Chebyshev 距离≤2；
- `min(abs(label_i-label_j),8-abs(label_i-label_j))≤1`。

兼容集合按真实物理像素 ID 去重；同一个场景分叉像素在不同链中的成员关系分别保留。
不允许加半径、合并断开的链、拟合新变换、插入虚拟场景点或跨分叉选路径。
A 对 i 的所有兼容物理像素取非空支持，允许不同 i 复用同一像素。
B 对每条 T 只选一条 S；同一条 T 的对应内部，i、j 都至多用一次，且满足下表顺序。
不同 T 可选同一 S/同一像素，保留跨链复用统计，不能宣传整物体全局一对一。

沿所有 owned 模板样本的 canvas bbox，使用 V14 的整数4×4格归属：
`col=4*(x-xmin)//(xmax-xmin+1)`，row同理，`cell=4*row+col`。令非空格数为 C，
每格样本数为 n_g。模板常量 `L=lcm(n_g)`、点权重整数 `W_i=L/n_cell(i)`，总分母
`D=C*L`。A/B 的分子都是支持点 W_i 之和；因此分数恰为占用格等权覆盖率。
L、分子、分母及 DP 比较使用任意精度整数，不使用 float epsilon。
通过门槛恰为 `20*numerator >= 13*D`。越界、遮挡及未匹配点不减少 D。

对一对链，n为T的评分样本数、m为S的物理节点数。开链按规范序从0开始；闭链也是唯一
物理 ID 的规范周期序列。固定模板规范方向，只枚举场景方向 d=+1/-1；两者共同反转不增加
新的匹配关系。m=1时仅保留+1。允许跳过任意模板/场景点，但不允许重复点或绕两圈。

| T → S | 线性化及必须枚举的切点 | 每方向最多 K 个切点 |
| --- | --- | ---: |
| 开 → 开 | T规范序；S规范序或反序 | 1 |
| 闭 → 开 | S规范序或反序；T从每个有兼容边的评分样本起旋转 | min(n,E) |
| 开 → 闭 | T规范序；S从每个有兼容边的节点起按d旋转 | min(m,E) |
| 闭 → 闭 | **T固定规范切点0**；S从每个有兼容边的节点起按d旋转 | min(m,E) |

E为这对链的不同兼容边数；E=0时分数0，不枚举空切点。闭场景切点t下的索引为
`j'=(j-t) mod m`（d=+1）或`j'=(t-j) mod m`（d=-1），并限定0..m-1严格递增。
闭模板切点s下 `i'=(i-s) mod n`。每个线性化都只包含每个物理 ID 一次。

**切点枚举完整性的理由：** 非空最优匹配的第一个被匹配点必在兼容边上，故无需枚举无边
切点。闭T→开S可把该开S方向中的第一个被匹配点所对应的T样本作为切点。开T→闭S以
最早T匹配点对应的S节点为切点。闭→闭时，先将匹配对按T的规范索引递增排列，其对应S
在某个方向至多wrap一次；以第一对的S节点为切点即可，T无需再次旋转。每个枚举输出
又显然是一个合法、至多一圈的顺序匹配，因而双向包含。这个简化依赖于**没有间隙罚分或
位置相关切点奖励**；以后加入它们必须重做证明，不能直接复用本合同。

## 5. 精确稀疏递推、平局与复杂度

固定链对、方向及切点后，把边转成严格线性序号 `(i',j')`。对每条兼容边定义

~~~text
F(i',j') = W_i + max(0, F(a,b) : a<i' and b<j')
~~~

最优值为所有 F 与0之最大值。这是加权公共子序列的兼容边 DAG，不是选最近点后再检查
顺序。n、m、E均可变化，不分配整个模板×整张图矩阵。

建议 native：按i'分组，Fenwick prefix-max只查询`j'<当前j'`，**整组查询全部完成后才
批量更新树**。这样不能让同一i'被用两次；strict prefix及单链唯一物理节点保证j也不
复用。每条边带唯一的原始 `(template_sample_id,scene_pixel_id)` 排序 ID。
相同最优权重的状态优先较小末边 ID；一个末边状态本身递归选择同规则的前驱。这对应
反向 witness edge-ID 序列的字典序最小值，避免在每次树比较中复制长 witness。
不同case同分时依次取最小 `(scene_chain_id, direction_order(+1先), template_cut,
scene_cut)`；再采用该case的规范前驱。A的诊断 witness取最小兼容物理像素 ID。
序列哈希是诊断绑定，最优性的验收仍由独立oracle重算。

对单条T，分别求每条S的各case最优值后取最大；再对所有T求和。各T之间允许复用的
约定使该分解恰好最大化全模板相同的4×4加权目标；不先最大化点数再事后算格权重。
必要不变量为 `0 ≤ score_B ≤ score_A ≤ 1`。同阈值下 pre-NMS接受集B⊆A；这个关系
**不推出**任何 post-NMS集合或召回的包含关系。

对一个候选，令P为有边的链对，`E_uv`为每对边数，`K_uv`为上表切点数，`m'_uv`为
出现于兼容边的不同场景节点数。只压缩秩、保持原顺序的实现，最多处理
`H = sum_{uv∈P} 2*K_uv*E_uv` 个edge-case状态；m=1时方向因子为1。
时间为 `O(sum 2*K*E*log(m'+1))` 次大整数加/比较，外加构图、边排序及兼容查询；若最大
整数位数为b，每次加/比较的位成本也计入，不写成无条件常数。流式处理一个case可把工作
内存控制在 `O(E + m')` 个状态；详细 witness必须能从保存前驱恢复，不能靠丢弃前驱假报
同样的内存。

半径2只给出每点25个场景物理位置，并不保证周期枚举便宜。每个像素的链成员数不超过
原图degree（孤点为1），故所有S的E总量可粗界为`200*n`；K仍可随n/m增长。闭链不能
直接按一次开链成本预算，也不能因超限改成固定切点、只取最近链或截断E。长重复孔、
全兼容标签、闭合平行轮廓和高分叉图必须作为成本反例。

## 6. NMS不单调及必须保留的身份验证

三个同类框按原分数/rank为a、b、c：

~~~text
a: score100, box(0,0,10,10)
b: score 99, box(5,0,10,10)
c: score 98, box(10,0,10,10)
GT: box(10,0,10,10)
~~~

`IoU(a,b)=IoU(b,c)=1/3>0.3`，`IoU(a,c)=0`。A全接受后，原NMS输出a/c；B只拒绝a后
输出b，c反而被压掉。以IoU≥0.5配GT，A有TP(c)，B没有TP。即使每候选B分数≤A分数且
B接受集⊆A，删掉一个验证失败的候选也可能间接丢失原来成功的GT。

本例需同时通过native、独立NMS及GT oracle；不能只测试A/B覆盖率包含关系。NMS保持
原 class-aware strict IoU>0.3、原 canonical score/字段平局排序，不用新分数重排。
拒绝的候选不能成为blocker。A/B分别对完整通过集重跑NMS，不能从C0 selected中做减法。
重复候选、相同score、边界IoU=0.3/0.5、多GT竞争及全拒绝帧均有合成例。

全部结果用原 allGT greedy assignment 重新配对，按
`(object,scene,image,GT_index)`比较原215身份是否保留。原 detection row与GT身份分开
统计；换模板/框仍必须实际达到正确IoU。负组合、逐对象/场景、eligible另口径、原身份
丢失/新检出及每个直接blocker均保留。没有raw合格框的FN无法被本验证器恢复；历史V28
有162个此类GT是这个限制的实例，不是对新机制的可恢复承诺。

## 7. 独立oracle、充分证据与完整预算

**源码/tiny先行：** 独立oracle不调用native切点、兼容边或Fenwick函数。对n,m≤3的所有
二分兼容图、四种开闭类型、两方向及模板点所有格分区（由分区计算上述真实格权重），直接
枚举部分单射并用原始循环顺序谓词判断合法性；比较精确最优分子，并检查native witness
合法、最优及规定平局。另有固定的n/m=4..8手写与seed固定case。穷举只证明该小域，
一般正确性依据第4节枚举完整性及第5节最优子结构论证。

必含：同链重复场景像素拒绝、跨模板链复用允许、逆序、只有反向可解、跨闭链接缝、两圈
伪解、返回分叉点的环、分叉不拼接、断链不连接、权重点数与格权重最优不同、越界分母、
空边图、零owned样本链、非零origin及第6节NMS反例。故意注入in-row立即更新、≤prefix、
重复端点、去掉周期枚举、跨链全局禁复用、浮点阈值及越界减分母，均须在所列case上失败。
只以手写/生成的小整数图运行，建议≤60秒、RSS≤512MiB、输出≤64MiB；超限保留失败。

**完整数值审计采用另一种递推：** 从eligible标签网格独立执行细化、分解、采样、所有权、
坐标/方向/半径兼容边，按全部400帧/六对象/C0候选重建。逐case在兼容节点的压缩秩上做
二维行式dense DP：`D[i,j]=max(D[i-1,j],D[i,j-1],D[i-1,j-1]+W_i[若有边])`，直接枚举
全部合法切点作为参考（闭→闭也可枚举两侧切点，需另计参考成本）。不复用native Fenwick
数据结构。可选择全切点或第4节已证明的单侧枚举，但冻结时只选一条。推荐全量audit仍用
单侧枚举，tiny的双侧穷举独立检验该化简。任何恒等简化（如E=0返回0）须事先声明。

最小充分证据包括：完整input/source/build/runtime pins；每个模板的上述来源、eligible
网格、全部链/点/权重；每帧的完整eligible网格和padding；完整原候选、GT及原C0输出；
每候选A/B精确分子/分母、接受标志、计数、选定case与最优witness；A/B完整NMS/assignment。
可无损分块压缩，但不能只留下哈希、TP或sampled witness。全网格加完整坐标足以让审计
重建兼容图，无需逐候选重复存同一25邻域。审计重新求最优值，不能仅确认native witness
是一个可行解。逐链标量及全部候选状态也应留存，以定位差异。

审计范围要诚实区分：这套数值oracle从完整**eligible标签网格**起独立重建后续算法，
不独立从RGB重新实现OpenCV灰度/warp/blur/Sobel/histogram。源图/warp/mask pins及C0
逐层回放是来源和重放检查，不等于独立像素梯度oracle。若需要该更强主张，须另写独立
像素算子并冻结容差/边界，另计解码与算力，不能在报告中追认。

建议以以下两个完整运行各自占用唯一重型槽，并纳入同一预冻结协议：

| 阶段 | wall硬上限 | RSS硬上限 | 输出硬上限 | 额外工作计数上限 |
| --- | ---: | ---: | ---: | ---: |
| native完整development | 90分钟 | 1.5GiB | 1GiB（含充分证据） | edge-case状态H≤5亿 |
| 独立全量数值audit | 4小时 | 1.5GiB | 128MiB（输入证据只读） | dense DP cell更新≤20亿 |

guard/execution日志另限64MiB，开始时至少5GiB空闲。每对case记录n/m/E、兼容链数、切点数、
方向数、H、树访问/DP cell计数、big-int最大位数；按对象、帧及全局汇总。独立审计的20亿
预算为实际所选参考枚举的所有`(n+1)*(m'+1)`之和，不按一次开链估算。预算尚未经实测，
不代表一定可跑完或任何实时性能承诺。若合成成本/证据预算表明不可行，先拒绝本路线；
不能只运行成本低对象再宣称全量通过。

超任一硬界：停止并保存已完成清单、原因、日志与计数，整体标记incomplete，不从子集做
准确率结论或把未处理尾部当拒绝/通过。改变算法或预算须另立明确successor，原失败保留；
不静默重跑同一reservation。可以先按冻结输入做纯metadata/文件库存预检；不能以真实
新分数试跑后调阈值。完整质量门槛通过后，才设计正式成对end-to-end性能测试，包含新
scene预处理、链构建、候选验证和NMS，不能只报有缓存的查询耗时。
