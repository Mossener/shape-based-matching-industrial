# C0 候选上的有序轮廓验证：独立设计草案

**状态：proposal；未实施、未冻结、未批准执行。** 日期 2026-10-23。本文供下一阶段科学可行性审查；不是可直接启动的实验协议。未编写验证器、运行 native、读取大 raw/bank/image/heldout、下载数据或修改 V31 冻结实验。V31 数值审计通过与 B 的准确率假设失败是不同结论；production 继续 V11，封存集不因本草案开启。

**目标：** 保留 RGB C0 的完整提议，再检查模板边缘能否由真实场景边缘链以链内保序、一对一的对应解释，降低杂乱环境误检，并保留 C0 已检出的全部 215 个 GT 身份。

**架构建议：** C0 搜索、分数、模板和框不变。A/B 使用同一份额外边缘/链证据；A 独立查询邻近方向支持，B 增加链内对应约束。各自过滤完整 pre-NMS 输入，沿原始 C0 候选顺序运行原 NMS，不以验证分数重排。本轮先不加入连续精修、低门槛提议、signed16、额外 mask 配方或逐对象参数。

## 证据与可证因果的问题

只读依据是 [V14 报告](../../../artifacts/quality_coverage/DEVELOPMENT_RESULTS_20261021.md)、[六对象失败分析](../../../artifacts/quality_failure_analysis/RESULTS.md)和 [V28 小报告](../../../artifacts/quality_failure_analysis/v27_rgb_empty_mask_losses/RESULTS.md)，没有打开它们引用的大输出。

- V14 已用固定姿态、半径 2、unsigned8 精确/相邻方向 bin、密集边缘及 4×4 空间平衡。对象 1 的门槛 0.65 保留 37 TP，但仍有 6397 FP，350/350 负帧报警；0.80 降至 1195 FP，同时降为 32 TP。它不是“只有少量稀疏点”的对照。
- V14 中各点独立借用局部响应，不要求响应位于同一条场景边缘链，也不阻止链内重复借用像素。**新增假设是观测对应的连接、顺序与链内占用约束，而不是再添加共同姿态或方向。** 所有候选本来就有共同平移/角度/尺度；给它拟合一个共同变换本身不构成区别。
- 原 RGB C0 的 400 GT 中，215 已匹配，162 无 IoU≥0.5 的合格 raw 框，23 有 raw 支持但最终未匹配。验证可改变后者的竞争，不能恢复没有提出的框；238 的历史 raw 最大容量只是乐观上界，不是可实现召回承诺。

**因果比较：** B 对 A 隔离链内顺序/占用这组约束，因为两者的像素、采样、方向、半径、评分归一化和门槛相同。A 对 C0 同时包含新采样/预处理，不能被解释为单独的链约束收益。B 对 C0 是最终产品质量比较。这个最小 A/B 仍不能把“同链、保序、一对一”三种作用单独拆开；若需要区分，应另立后续消融，不能本次临时加臂。

## 完整输入、坐标与候选顺序

沿用对象 `[1,2,5,8,12,17]`、全部 400 development 帧及原训练视角/姿态产品；对象 25/29、tiny heldout 和扩展 heldout scenes `[11,14,15,16,17,18,19,20]` 全部排除。不得依据本轮逐对象表现挑对象、帧、模板或阈值。

未来实验输入应绑定已审计 C0 的完整 post85、pre-NMS 候选、pose metadata、构建/输入/数值审计回执和完整文件清单。这里的“raw”指当前审计管线保存的 consolidated 候选，**不是未剪枝的整个搜索空间**。不改变实际 matcher threshold85、post-score85、模板选择或 consolidation；不混入 P/B 的候选。

- 逐原始 rank 为每条候选生成验证记录，包含零检测帧。不能仅验证 selected 检测、TP、正帧、top-K，或把未处理尾部当成拒绝。
- fallback/fused 如有完整逐字段/score-bit 相等证据，可以只计算一份验证值，再对等价身份复用；否则两条路径必须分别验证。不能以“预期相同”代替绑定。
- 训练 pose 用 `(object, source training image, angle, scale)` 连接，再绑定 C0 template ID/feature origin；不得跨 bank 直接复用数字 ID。
- 复用 V14 已验证的 canvas→template-origin→padded-scene 变换；保留负相对坐标，padding 与 `tl_x/tl_y` 只应用一次。像素越界保持原分母并记 unsupported。原框、原 match 坐标和原 score bits 全部保持。
- B 拒绝一个候选后，该候选不能再成为 NMS blocker。A/B 分别以原 C0 相同排序运行完整 NMS；同时保留原 C0 输出作正控。并列规则沿用现有 canonical order，不按验证分数重排。

## 共同边缘证据：建议路线及待选项

以下是审查用具体建议，**数值和分叉/闭环规则均尚未冻结**。确定一条路线后应先写完整合同和 tiny oracle，再进入真实数据；不能依据真实 TP/FP 选实现。

**推荐起点：** 保留 V14 的 RGB warped crop/官方训练 mask、7×7 blur、Sobel 与 unspread unsigned8 histogram 方向；模板强阈值40、场景弱阈值20，兼容方向为精确/相邻 bin，L0 Chebyshev 半径2。mask 只限定训练证据区域，不把 mask 边界直接合成为梯度标签；不改 C0 bank。A/B 对相同输入字节使用同一新证据。

对有效方向像素构建二值支持图，再以确定性的 Zhang–Suen 双子迭代细化为单像素图；保留幸存像素原有方向标签。8 邻域构图，所有节点、邻边、链按稳定 y/x 排序。先记录细化前后连通分量、分叉及环数量，暴露厚边缘与对角接触带来的拓扑变化。该操作不是已证明最优的边缘算法；另一候选是方向非极大抑制后再做 hysteresis，不能两种都跑后择优。若细化本身在 tiny 合成图中产生不可解释连接，则这条路线先不进入真实质量实验。

| 问题 | 推荐审查起点 | 其他待选项与代价 |
| --- | --- | --- |
| 分叉、交叉、角点 | 度不为2的节点作为端点，将图拆成最大 degree-2 链；不猜测跨分叉“真实物体轮廓” | 以切线连续性连接分支增加新参数及歧义；会把局部链约束变为更复杂的路径搜索，暂缓 |
| 模板采样 | 沿模板链每2个 L0 像素弧长取一个实际图节点，含开链两端；重复评分坐标由最小链ID拥有，其他链保留拓扑端点但不重复计分。可用轴步1000/对角步1414的整数弧长及稳定 y/x 平局 | 按固定总数重采样会让长/短、断链比例改变权重。场景链保留全部细化节点作观测ID，不另隔点丢弃；A/B均用同一集合 |
| 极短链/孤点 | 不静默移除；纳入 A/B 相同分母、单独分项。孤点只能提供位置/方向证据，无顺序判别力 | 最小链长删除会引入新的选择效应；若确需删除，须在真实读取前固定并报告比例 |
| 闭环与起点 | 推荐周期顺序允许一次 wrap，场景像素每圈最多使用一次；正反向均比较，取确定性最佳 witness | 固定最低 y/x 为开链起点成本低，但会引入接缝假失败；全周期求解的精确性与成本必须先证明，不能靠近似与 A 比较 |
| 遮挡/断链 | 未匹配模板点记0、保留分母；允许跳过点但不把断开的场景链自动拼接 | 一条模板链映射多个场景链可能保留遮挡召回，却弱化“同链”假设；分段数量/间隙预算不能在真实漏检后补救 |

模板与场景链的方向不依赖遍历方向，仍用同一 unsigned8 梯度标签。细化会令局部边缘离原中心移动，必须让 A/B 同样承担这项变化。训练黑色 warp 外围可能制造强边缘，场景遮挡/反光又可能抹去它；保留来源/alpha 邻域诊断，不据结果屏蔽不利点。不能将官方 mask 当作真实场景中所有边界必然可见的证明。

## A/B 对应、评分和明确边界

对每个模板样本 `p_i`，两臂使用完全相同的兼容集合：距候选姿态预测点半径≤2、方向精确/相邻、有效的场景采样像素。记录每像素 ID、链 ID、链内弧长及相同的 in-bounds 标志。

- **A（独立支持）：** 兼容集合非空即支持，允许不同模板点复用同一场景像素。
- **B（链内有序支持）：** 对每条模板链，选择一条场景链和遍历方向，求保序、严格一对一匹配；一个模板点或场景像素在该对应中最多用一次。推荐直接最大化与A相同的4×4格归一化支持权重之和，而不是先最大化点数、再由任意平局witness改变格权重分数。位置/方向兼容集合不变，不拟合额外变换、不扩大半径。同权重按链 ID、方向和 witness 字典序打破平局；权重精确比较/数值边界必须在tiny合同中选定，不能以浮点近似结果事后择优。
- 对开链使用顺序子序列，对闭环按最终审查选定的周期规则；缺失点照样进入分母。链内没有匹配的点权重为0。A/B 都用同一4×4占用格等权平均，不能给 B 改成容易匹配的长链加权。

**第一版的“一对一”限定在同一模板链与场景链的对应内部。** 不同模板链可能选择相同场景链/像素，必须记录跨链重复占用率；不把它宣传为整物体全局一对一。如果必须禁止跨链复用，就需要额外全局分配求解，复杂度及多候选歧义均变化，须在冻结前另行选择，不能实现时偷偷替换。

局部保序也可能被短链、杂乱中的长直线、重复孔、近似对称边缘满足；折叠轮廓和分叉拆链会削弱约束。它不证明物体身份。不同物体具有相同投影轮廓时，2D 几何本身无法区分；不要通过对象专用门槛掩盖这种限制。对称物体允许正反顺序/周期移位不等于角度姿态正确。

连续方向可用 `cos(2Δθ)`，但本次不改方向表示。signed16 把极性保留到360°，角步长与 unsigned8 相同；反号可能移动8个bin，物体反光/背景变化可能局部反转。它既不自动更精细，也不增加边缘拓扑。更细 unsigned16 与连续方向、极性鲁棒性应分别立项。

## 主质量门槛：建议而非批准结果

冻结前必须选定一个门槛，之后不扫描覆盖阈值、半径、允许断段数或逐对象参数。建议先以历史 V14 的0.65作为唯一覆盖门槛审查起点，但新采样的分数分布尚未知；它不是已验证可用的阈值。

**不可让步的产品条件：** 与同输入 C0 正控精确一致；B 保留 C0 已检出的全部215个 `(object,scene,image,GT index)` 身份；总 allGT TP≥215。身份保留与原 detection row 保留不同，换模板/框仍须按原 IoU≥0.5、原 greedy assignment 重新确认；不得只用净 TP 抵消丢失身份。所有负帧、有效可见度、逐对象/场景与模板失败项保留。

**实质 FP 收益需由 root 在看新分数前批准。** 可供审查的开发筛选目标是 FP_B≤0.5×FP_C0，即≤21,056；这是对 C0 的工程筛选建议，仍远非工业误检标准，也不是统计显著性结论。不得把之前提过的“B 比 A 少50%”当成已批准门槛。A/B 因果报告应在相同215身份保留条件下列 FP 差、负帧报警差和逐场景成对变化；若 A/B 召回条件不同，明确报告对应的收益/损失，不将其称为纯误检收益。

400帧只来自8个既有开发场景，帧与类别共享背景。优先报告逐场景/对象差值，不能按2400对象帧独立计算一个过度自信的 p 值。是否使用场景聚类区间及其小样本局限应预先固定；“显著下降”首先是预先批准的工程幅度，不靠事后选统计方法。开发通过后仍须另审确认性方案；本草案不授权解封。

## 规模与硬预算：只由小报告估算

V28 小报告给出 C0 **每条路径457,279条 raw**、42,327条 selected（215 TP+42,112 FP）。V17 较早报告为457,376条，说明不能混用历史 run；未来必须从选定 C0 的既有 manifest/独立审计绑定确认完整候选数，**457,279只是当前估算依据，不是已读取核验的 V31 清单**。

每个对象平均约76,213条，2400对象/帧任务平均约190.5条，二者均不是峰值预算。若每候选128/512/1024个样本，单纯25像素邻域查询已约14.6亿/58.5亿/117亿次；链匹配还要额外计算。不能因为只剩约4.2万 selected，就按该数量预算 pre-NMS 验证。

建议未来分两阶段冻结资源：

1. **源码/tiny 可行性：** 只用手写链图测精确求解和状态增长，≤60秒、RSS≤512MiB、输出≤64MiB。独立穷举 oracle 对比优化实现。若周期求解、分叉或占用规则无法在此证明，不进入真实图像阶段。
2. **完整 development：** 单重型槽，建议 wall≤90分钟、RSS≤1.5GiB、全部输出≤1GiB；这些是待审批上限，不是可达延迟预测。训练模板链缓存、400次场景预处理、完整候选验证与NMS分别计数/计时。禁止dense `N_template×N_scene`全图矩阵；推荐在相同兼容边上做稀疏非交叉匹配，但必须由 oracle证明精确性。最坏图仍可过大，超限保留失败证据并报告完整性失败；不能截模板点、改门槛、top-K或只报完成帧。

为压缩证据，真实阶段可保存全部候选的标量、计数与对应 witness 哈希，并按预先固定的候选 rank 等距抽样保存详细 witness；抽样仅限制诊断输出，不能限制实际验证。独立全量数值审计需要的最小充分证据格式应在执行前论证；单一哈希不能证明对应最优或从像素生成正确。计时包含新预处理，不能只计 lazy 查询来宣称加速。质量门槛未过则不启动正式配对性能基准。
