# Successor design only: binary source with an empty feature mask

Status: static assessment requested by the parent. No implementation, training, image access or parameter change belongs to this proposal. The current source-only six-object experiment remains unchanged.

The proposed factor is solely the third argument to `addTemplate`: compare `addTemplate(binary_source_clone, class, unchanged_warped_official_mask)` with `addTemplate(the_same_binary_source_clone, class, cv::Mat())`. The original warped official mask remains the source of the binary training canvas, its silhouette bounding box and pose metadata in both arms. An empty feature mask does not mean an empty source image or empty object geometry.

The frozen V11 implementation supports this policy. `ColorGradientPyramid::extractTemplate` erodes a supplied mask once and permits a gradient candidate only inside that eroded mask. With an empty mask, `local_mask` remains empty and the same gradient/NMS/threshold/scattered-selector code scans the whole valid canvas interior. The source-side blur, Sobel, orientation filtering and gradient magnitudes remain identical. `pyrDown` downsamples the source in both arms and only resizes a feature mask if one exists; the empty feature mask stays empty at L1. Thus this is an explicit feature-selection-mask change, not a replacement extractor or a tuned dilation radius.

The two fixed toy failures show that binary source plus the original feature mask can fail. They do not uniquely identify erosion/NMS as the cause or predict whether the empty-mask arm succeeds. A later independently frozen protocol should retain both successes and failures without changing feature budgets, thresholds, training views, scale/angle grids or masks after seeing results.

The existing source-origin mapping remains valid when features extend beyond the official silhouette. V11 `cropTemplates` derives each layer's `tl_x/tl_y` and declared extent from selected feature coordinates, rounding the common minimum to an even source coordinate. The detected official silhouette box is still `match - input_padding + official_warped_mask_bbox_origin - actual_template_tl`, with the unchanged official box width/height. The formula does not require the feature top-left to lie inside that box. Record the actual `tl` from each new template; never copy the old bank's `tl`, equate numeric IDs across arms, or replace the official box with the feature bounding box.

With a pure 0/255 canvas, useful gradients arise from foreground boundaries, including holes and any true mask discontinuities. The empty feature mask can select maxima on either side of a silhouette edge after blur. It may also select weak or unintended response near a canvas boundary if finite filter support reaches it. Preserve the original black canvas, training border 16, nearest-neighbor warp and unchanged pyramid. Before development decoding, record every loaded feature coordinate, actual feature-to-canvas-edge distance and source silhouette geometry. Do not respond to an edge-distance observation by silently increasing border, eroding/dilating the object, trimming features or changing the pyramid.

The complete-bank padding scan remains necessary because new feature minima/extents and successful poses can change. Use actual maximum coordinate plus one at the coarse layer as well as the declared extent; preserve left/top 64 and the grid phase. The current source-only/RGB shared-padding freeze cannot be reused as proof for a new empty-mask bank. A successor should derive and freeze its own one-size union of all six objects and both binary feature-mask arms before any new development decode. If an entire original-mask arm is zero-success, explicitly record that arm as unavailable/incomplete and report training feasibility; do not fabricate an empty detector's valid quality metrics. Any later quality comparison against RGB at a different padding is an independently labeled historical baseline, not a causal feature-mask-only A/B result.

Cross-arm retention must use GT IDs and pose keys `(object, training_image, angle, scale)`, since successful dense numeric IDs can differ. For both arms preserve all 20,736 attempts, actual per-layer feature counts, unsuccessful poses, and independent numeric verification. Keep heldout images and reserved objects 25/29 sealed. The current experiment's results, budgets and records remain a separate version; this proposal cannot be folded into them after observing a failure.
