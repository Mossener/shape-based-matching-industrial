# Independent numeric audit source review

The auditor uses only Python's standard library and four modules owned by this
independent review sibling. No target probe/evaluator/matcher implementation is
imported. `evidence2.safe` denies image/SMD suffixes and compressed YAML template
banks even for hashing. Native executable/compiler/runtime members are hashed
only as inert bytes.

`numeric2.py` reconstructs sums from response digits and uses two explicit
binary32 rounding steps. Coarse traversal preserves the native flattened span
and zero tail; features skipped at the stream origin contribute zero while
remaining in the actual-feature denominator. Coarse threshold is strict `>85`,
fine threshold is inclusive `>=85`. Maximum selection uses the first strict
row-major improvement, including the all-zero `(-1,-1)` sentinel and all 256
tie positions.

`traces.py` joins native job IDs to exact object/frame/arm/template identities,
independently enumerates reachable parents including clamp and C++ truncation,
and reconstructs deduplicated global window ownership. It compares complete
cell coverage and feature coordinates/order/labels within and across jobs.
Counts/bounds are checked against loaded-layer aggregate evidence. Parent links
are checked as a complete exact set. Physical scores preserve the distinction
between per-feature domain errors and parent-conditioned local skip behavior.

`audit_main.py` streams gzip CSVs by owner. Coarse/local raw cells use compact
unsigned-short arrays; complete pre raw archives are read one frame at a time,
retaining only relevant template occurrence counters. All post raw records for
each frame participate in NMS, with exact selected fields/score bits and both
allGT and eligible/ignore assignment compared against preserved V22 selections.
Minimum representative IDs are independently recovered from complete pre
records for traced equality keys, rather than inferred from only a probed
subset. IoUs use each pre/representative template's own geometry.

`evidence2.py` binds the approved immutable Phase2 plan, native dataset freeze,
GREEN and three RED controls, exact generated preprocessing slices, declared
source/build closure, complete output membership, command/reservation/watchdog
receipts, and pinned passed Phase1 audit. It rehashes all 3,210 opened inert pins
after the numeric audit. Twelve serialized bank pins in the historical
`numeric_pins` field are compared only as declarations from the immutable prior
plan and its pinned passed Phase1 audit. The bank bytes are never opened. The
first preflight attempt that caught this historical naming mismatch remains in
`run_numeric_audit_20261022_v1/failure.json`.

Verification retained 39 passing synthetic tests (`all_green_v4.txt`), including
an eight-gzip end-to-end fixture, mutations in every output stream, owner/order
and coverage errors, skip/tail/binary32/threshold/maxima/tie errors, complete
parent-link errors, original RGB control loss, representative geometry and
multiplicity, NMS blockers, both GT assignment modes, build/stage mutations and
nonexistent serialized-bank paths. Genuine earlier RED runs remain unchanged.

The root separately authorized the fresh v2 numeric audit. Its result is
`run_numeric_audit_20261022_v2/result.json`, SHA256
`1710a1b3fe934ad73b8484b24527a99c2dddcdc6c20cca82aa2c3860ba724ea8`.
It passed all 426 full-class frame arms and 215 original RGB positive controls.

Limitations: digits and complete serialized features are native observations,
not independent pixel/template reconstructions. A same-pose trace audit is not
an accuracy improvement or a speed benchmark. In particular, the one binary
same-pose traced TP after full-class NMS is not the complete binary arm's TP
count; the preserved binary arm retains 148 of these 215 RGB TP identities.
