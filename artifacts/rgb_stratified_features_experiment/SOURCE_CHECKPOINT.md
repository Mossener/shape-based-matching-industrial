adapters, independent numerical auditors and synthetic source checks. It is
not a completed recognition or speed experiment and has no optimization tag.

restores exact pinned bytes. Generated numeric/text records and frozen source

as text. No historic receipt or input is normalized to satisfy Git style checks.
