# RGB feature stratification: frozen V31 design

This is a new isolated algorithm experiment. The primary arm B uses a fixed
contour-support/interior allocation. P is its pooled ablation; C0 is the
unaltered official-mask RGB control. No production default changes, native
execution, dataset-image access or template-bank payload reads accompany this
design. The originating proposal is pinned in `SOURCE_ORIGINS.json`.

## Question and decision

V30 official-mask dilation reduced FP but lost 30 TP, failing the registered
accuracy gate. V22 binary and V27 RGB empty-mask results also lose control
identities. Their different selected feature regions support testing explicit
feature competition; they do not identify an optimum radius or mixture.

The question is whether balanced contour-support and interior RGB features
improve complete detection quality relative to the original control, and
whether quotas explain any difference from an otherwise identical pooled
sampler. B is the primary candidate before pilot results. P never substitutes
for a failed B hypothesis after results are seen.

The primary development gate stays `B allGT TP >= 215 AND FP < 42112`, subject
to exact C0 common-padding reference reproduction. All per-object/scene,
eligible, negative-frame and retained/lost/gained identities must be reported.
A passing development gate does not establish industrial generalization or
authorize promotion. Held-out evaluation requires its own later frozen
protocol; held-out inputs are not opened in this experiment.

## Fixed source and geometry

Use exact V11 revision `b25df46f6ddf9c24fb43f5836f1414dc38c8caed` in a new
namespaced source copy. Preserve grayscale RGB source, official-mask ROI,
affine, INTER_LINEAR source warp with zero border, INTER_NEAREST mask warp,
Gaussian/Sobel/hysteresis and 5x5 NMS semantics, thresholds20/40,
T=[4,8], 32/16 requested budgets, poses, scoring85, external NMS.3, GT IoU.5
and eligible visibility.5. C0 banks are loaded from the reviewed frozen
official-mask RGB inputs, never regenerated by the new sampler.

Let V0 be the actual 8-bit official warped selection-mask Mat. For each
following layer, core semantics are
`size=(floor(src.cols/2),floor(src.rows/2))`, `src=pyrDown(src,size)`, and
`Vnext=resize(Vcurrent,size,INTER_NEAREST)`. The layer mask is not grayscale
pyrDown, rewarped geometry, direct rounded coordinates or a threshold128
image. All nonzero byte values count as object; define Ml=(Vl!=0) only after
the exact nearest resize. Nearest resize preserves selected byte values;
odd source sizes require the actual source/destination ratio, not simply
sampling every second pixel. The planned public training masks retain their
inherited binary0/255 validation, while literal mask tests also cover
nonzero1/7/128 to protect the core nonzero semantics.

Use exact signed integer Chebyshev distance to the opposite-valued mask,
with zero exterior extension. Inside boundary pixels are +1 and immediately
outside pixels -1. The radius r=4 is fixed from 7x7 Gaussian plus 3x3 Sobel
center support. It is not selected from development results and does not bound
hysteresis/NMS/global-selection dependencies.

The candidate domain D is Ml dilated by a9x9 all-one kernel with zero exterior,
intersected with the unchanged two-pixel NMS-loop canvas margin. Collect C
with the original mask-before-traversal NMS and gradient thresholds once
over D. Its members have stable accepted-candidate row-major ordinals.
Partition this single C into contour-support S=(signed distance<=4) and
interior I=(signed distance>4). Both strata include only accepted members of
C; never collect NMS separately within strata.

The shared generator is invoked exactly once for each of20,736 poses and each
of two layers:41,472 immutable pools. Both layers must be generated and
recorded even if L0 has too few candidates. Both samplers reference the same
pool ID and digest; they must not rebuild gradients, masks or NMS. This
requires a new training orchestration path because historical addTemplate
returns early on L0 failure. That orchestration change is isolated and leaves
C0 source/banks untouched.

## Exact sampling rules

Let K=32 at L0 and16 at L1; N=|C| and t=min(K,N). N<=4 means an
insufficient-features layer for both new arms. For N>4, each sampler must
return exactly t distinct candidate ordinals. A new-arm template succeeds
only if both layers succeed; no partial template enters a bank. Consequently
P/B success/failure statuses must match for every pose. A mismatch is a
correctness failure, not a quality outcome. The41,472 arm-level attempts and
82,944 arm/layer statuses are all retained.

Both samplers use deterministic farthest-first selection. With no selected
features, choose the greatest-magnitude eligible candidate. Otherwise maximize
the minimum squared Euclidean distance to all already selected features.
Tie-break by descending finite float32 magnitude, then original accepted
row-major ordinal. Compare checked signed64-bit integer squared distances;
preserve original label, theta bits and chosen order. Real candidate collection
visits each coordinate once; identical coordinates in synthetic sampler tests
remain separate ordinals and can have zero distance. Never repeat an ordinal.

P applies this rule to all remaining members of C.

B computes quotas from t, not K:

1. qS=ceil(t/2), qI=floor(t/2).
2. If |S|<qS, transfer qS-|S| from qS to qI. If |I|<qI, transfer
   qI-|I| from qI to qS. As N>=t, both deficits cannot remain after this
   operation. Record initial/final quotas and each transfer.
3. Request strata alternately S,I starting S. Skip a fulfilled stratum without
   consuming an output position. Select its farthest-first candidate against
   the entire selected set, not only its own stratum. Continue until t outputs.

For t5, initial quotas are3/2; for t16,8/8; for t32,16/16.
For N5,S1,I4 the final quotas are1/4. Empty strata deterministically borrow
all required slots. There is no threshold relaxation, weak-feature synthesis,
per-object fallback or post-quality quota change. Historical V11 actual counts
above requested budgets stay unmodified; exact new-arm counts are intentional.

After selection use the unchanged cross-layer `cropTemplates` arithmetic and
serialization. Official box metadata still comes from the warped official
mask, not from selected-feature extrema. C0 keeps its original feature counts,
origins and feature order.

B/P isolates quotas conditional on this pool and sampler. P/C0 includes domain
expansion and selector replacement; B/C0 is the total product-quality change.
Neither comparison alone proves a boundary-feature cause or optimal mixture.

Replan one shared input canvas over all18 banks using actual feature max+1
and own-layer origins. Preserve left/top64 phase and alignment16. Begin at
848x832 with padding[64,64,64,228]; enlarge only right/bottom by the fixed
geometry formula when required, within axis2048/pixels2,097,152/estimated

to match its frozen V30 control on all evaluated frames; otherwise stop
primary interpretation and preserve the geometry difference for a successor.

## Complete, bounded evidence

Record the whole accepted pool, not selected features only. Stream one pose
and one layer at a time, write lossless numeric packs, and release transient
buffers; both samplers consume the immutable in-memory pool before release.
Candidate payloads use a canonical little-endian21-byte record:
ordinal:uint32,x:int32,y:int32,label:uint8,magnitude_bits:uint32,theta_bits:uint32.
All records preserve source order. Pool headers retain pose/layer, full canvas,
K/N/t, raw mask/domain digests and coordinate/score validation. Compress without
quantization or omitted candidates. Save both actual Vl masks as complete
lossless uint8 numeric arrays so the independent oracle can reconstruct
nonzero membership, distances and strata without OpenCV or image decoding.
Do not duplicate pool/mask packs for P and B.

Hard limits are1.5GiB process RSS,90minutes training wall time,4GiB physical
numeric output and32GiB logical uncompressed payload; max2,097,152 candidates
per pool and64MiB per public compressed shard. Split at pool boundaries;
record content and compressed SHA/size and complete ordered shard membership.
If a single pool cannot fit the shard ceiling, fail explicitly; do not split
or silently recode a pool mid-run. Check disk free space of at least8GiB
before training. Guards cover all native output files and buffered/temporary
output. Failure preserves completed shards, incomplete current shard, counters,
reservation and source/input pins, and prevents quality execution. A successor
may revise resources under a new protocol; it may not truncate, sample or
relabel the original run as complete.

The independent oracle reads all pool records and complete numeric mask maps,
recomputes nonzero/resize fixtures, distances/strata, quotas/borrowing and all
selected ordinals, using full pairwise distance recomputation. It checks every
attempt and serialized field; no original sampler import or precomputed
stratum trust. Real RGB magnitudes remain native observations, not independent
pixel recomputation. Small literal gradient/NMS maps test candidate collection
semantics separately. Publish no raster images or private magnetic/SMD data.

## Full evaluation schedule

Use the exact inherited432 training RGB/mask pairs, all72 views/object,
12 angles and4 scales, six objects[1,2,5,8,12,17]. New-arm attempts total
41,472; the shared loop implies864 image decodes if completed, to be recorded
as expected until an actual counter verifies them. Retain failures/exception
reasons; a zero-success object or extraction exception stops comparison.

Use all400 inherited development frames, including negative object/frame
pairs, and fixed8 pilot /64 timing flags. Do not read/decode/match held-out
scenes[11,14,15,16,17,18,19,20] or objects25/29. Private magnetic/SMD
regression remains separate, local and unchanged; it requires its own bounded
regression run and is not included in this public-call budget.

Matcher stages are one reservation each: old gate96; pilot288;
development14,400; timing29,952. Pilot is an execution check and cannot select
parameters, arms or whether to omit the full set. Timing uses64frames x6objects
x6arm/path variants x(1warmup+12measured) calls; it has27,648 formal rows,
4,608 per variant. Rotate six variants by(frame ordinal+round)mod6, giving
every formal order position exactly twice per object/frame. Every native
timing call compares complete ordered raw fields and float32 score bits to its
own saved development reference. Independently verify CSV schedule/counts and
statistics while retaining the limit that timing CSV does not reconstruct
the full output of each timed call.

At most one heavy native or numeric-audit job runs at a time. Freeze actual
compiler, two-TU dependency/link/runtime closures and transitive Python source
pins before execution; verify them and dataset allowlist bytes before/after.
Follow training, independent training+geometry acceptance, old gate, pilot,
development, independent quality audit, then separate timing and its audit.
Accuracy failure does not prevent measuring a fixed failed candidate's cost,
but it always prevents promotion.
