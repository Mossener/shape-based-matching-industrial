Standalone microbenchmark; not end-to-end matcher performance.
Sizes: 768x576, 896x704, 1024x768. T=4,8.
Source: fixed-seed sparse orientation masks (87% zero, 12% one bit, 1% arbitrary mask).
Every configuration is byte-checked before measuring.
spread_scalar_t2 uses safe original T*T OR loops (compiler may auto-vectorize).
spread_original_simd is the immutable production baseline, not the scalar reference.
response_original_simd_linearize is original computeResponseMaps plus all eight linearize calls.
response_fused is ResponseLUT::linearize, with the LUT constructed outside timing.
Kernel order rotates each repeat and reverses each rotation block; warm/evicted conditions interleave each repeat and swap which comes first.
Each kernel has two excluded initial warmups. warm: an extra identical untimed call immediately before each sample.
evicted: read one byte per 64-byte line of 64 MiB before each sample, outside timing. Approximate cache eviction, not a hardware guarantee.
Existing output allocations are reused; original response still allocates its internal lsb4/msb4 buffers as shipped.
Single OpenCV thread. No I/O/checksum/eviction included in timing. Repeats=15.
Compare medians against original_simd; no speedup claim based only on scalar baseline. Raw order/times preserved.
