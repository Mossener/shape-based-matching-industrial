# V25：同姿态评分与金字塔路径诊断

二值模板丢失的67个原有真阳性，在固定原RGB命中姿态、对应物理位置及预定邻近网格点上的细层分数均低于85。这支持下一轮检查模板特征和评分，不能把全部漏检归因于粗层剪枝。本版没有更改生产算法、阈值或默认模板，没有新增速度或准确率收益。

## 固定范围与验证

沿用V24全部215个RGB真阳性，含67个binary丢失身份和148个保留对照。按训练图、角度、尺度连接两种模板的同姿态，共430个任务；模板编号不作为跨臂姿态身份。范围为213个目标/帧、175张开发图，留出图及对象25/29未读取或匹配。

原生运行430次粗层评分、7185次local-map和7185次fused-maximum内核，保存73,337,912个逐特征响应值、3,024,440个网格分数、751个预定细层点和12,016条父窗口连接。没有重跑完整类别搜索或调用公开`Detector::match`；完整候选及NMS使用V24冻结记录。全部215条RGB正控复现，原生/scalar分数逐float32位相等。

三个注入错误分别被粗层、局部响应和winner oracle拒绝，GREEN通过。独立Python审计重算所有响应和、分数位、窗口最大值/平局、父连接、代表框、完整426个类别帧的NMS和两套GT分配，并核对V24全部1,312,006条pre及227,816条post。39项纯合成测试通过，实际审计核验3210个惰性证据pin。初次审计在读取候选CSV前因旧清单混列模板库而停止，失败保留；修订后模板库只核对冻结声明及其先前审计绑定，未打开模板库字节。

## 观察结果

以下计数只描述固定姿态和预定邻点，不是完整模板库的召回率：

| 二值同姿态邻点路径 | 原有67个丢失身份 | 原有148个保留身份 |
| --- | ---: | ---: |
| 所有可达粗层父被拒绝 | 23 | 13 |
| 有粗层父通过，但通过父窗口的最高细层分数均不足85 | 44 | 63 |
| 邻点分数不足85，窗口内其他winner通过 | 0 | 26 |
| 邻点分数通过，但首个最高分位置移走 | 0 | 25 |
| 预定邻点实际发出 | 0 | 21 |

23个粗层全拒的丢失案例，在全部反事实细层窗口中也没有winner达到85。另外44个中，只有1个被拒父的反事实窗口winner达到85，其预定邻点仍不足85。因此，单独放宽粗层门槛不足以恢复这批固定位置的低分路径。

全部215个二值同姿态任务中，39个物理锚点达到85、46个有邻点达到85，72个有某个父窗口发出候选；这些支持全部来自148个保留身份。追踪代表框经全类NMS后仅1个仍支持目标，不能写成二值整体只有1个TP。补充的完整pre分析确认，148个保留身份中147个实际选中TP来自其他姿态，76个在完整同姿态pre中都没有GT支持；该补充统计与独立审计的原始字段分开记录。V22的整体结果仍为原215个身份中保留148个、丢失67个；后者分57个无合格raw候选和10个NMS损失。

179个二值物理锚点不落在原生T4/offset1网格上，均有定义良好的物理分数；off-grid不等于检测失败。响应数字来自冻结的原生响应内存，独立审计重算数字算术和后续决策，没有独立从像素重新实现梯度/响应构建。采集及审计总时长不作速度基准。
