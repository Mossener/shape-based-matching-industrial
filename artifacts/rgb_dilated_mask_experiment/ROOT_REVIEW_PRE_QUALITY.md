# V29：训练与几何的独立验收

本阶段验证官方掩膜逐层膨胀方案的训练可行性，尚无识别准确率或速度收益结论。生产核心继续冻结在 `b25df46f6ddf9c24fb43f5836f1414dc38c8caed`。

唯一算法变化是实际特征提取层内同参数的 `erode` 改为 `dilate`。RGB 灰度源、原官方 warped mask、姿态、梯度阈值、请求特征数和几何保持原配方。它会容许一层像素范围内的外侧位置，不构成外轮廓环，也不代表已经证明新增特征有效。

六对象完整训练共 20,736 次尝试，生成 20,712 个模板，保留对象 1 的 24 次特征不足失败，OpenCV 异常为 0。两层实际特征数范围 5～43，未按请求的 32/16 截断。训练报告峰值工作集 64,069,632 字节；864 次 RGB/mask 解码由完成的固定循环推导，未使用解码钩子独立计数。

全十二个 control/treatment 模板库的 77,822 层联合规划严格通过 848×832、对齐 16、补边 `[64,64,64,228]`，没有扩大画布或删除模板。估算动态内存为 361,234,432 字节，不能视作实际匹配峰值内存。

root 重新校验了实际训练构建的五条编译器命令、工具和运行依赖、两 TU 的实际依赖，以及训练/规划输出、执行记录、预留记录和训练 864 个图像字节 pin；原生训练与规划均 exit 0。字节校验会读取允许的训练图像文件，但不解码图像。root 的新鲜源契约测试为 15/15，另有后来新增质量闭包测试在 agent 的最终源套件达到 16/16；验收标记的两项合成测试也由 root 实际运行通过。
